# Further Education Networks Data Schema

## Structure

Each entry should follow this format:

### For Networks, Communities of Practice, and Membership Organisations:

```json
{
  "name": "Full name of the organisation/network",
  "region": "English region name",
  "memberCount": "Number or range (e.g., 50, '50-100', 'Unknown')",
  "membershipTypes": [
    "Type 1",
    "Type 2"
  ],
  "website": "URL if available",
  "description": "Brief description",
  "contactEmail": "Contact email if available",
  "notes": "Additional notes"
}
```

## Membership Types (Common Examples)

- Full Member
- Associate Member
- Affiliate Member
- Corporate Member
- Individual Member
- Institutional Member
- Student Member
- Honorary Member
- Partner Member

## Categories

1. **Regional Provider Networks** - Networks that connect FE providers within a specific region
2. **Communities of Practice** - Groups focused on sharing knowledge and best practices
3. **Membership Organisations** - Formal organisations with membership structures
