**Q: What if AELP doesn't respond?**
A: Use the alternative approaches in the Action Plan - LinkedIn, web search, contacting organizations directly.

**Q: How do I know if I've found the right person?**
A: Cross-reference across multiple sources. If someone's LinkedIn says "Spoke at AELP 2024" and you find them in a conference photo, likely correct.

**Q: Can I contact speakers directly?**
A: Generally yes, but be professional and explain why. Check with AELP first if unsure.

**Q: What if workshop details have changed?**
A: AELP often updates programs closer to the event. Check back regularly.

**Q: Should I attend networking events to find this info?**
