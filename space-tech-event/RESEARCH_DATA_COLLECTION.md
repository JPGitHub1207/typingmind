## Data Collection Best Practices

### 1. Regular Updates
- Update databases weekly during active research
- Set calendar reminders
- Don't let data get stale

### 2. Data Quality
- Verify contact information
- Cross-reference multiple sources
- Note data confidence levels

### 3. Organization
- Use consistent naming conventions
- Tag and categorize entries
- Maintain version control

### 4. Privacy & Compliance
- Follow GDPR for EU contacts
- Get consent for data storage
- Secure sensitive information

### 5. Analysis
- Review data regularly for patterns
- Share insights with team
- Use data to make decisions
