# Why the Word file downloads and the spreadsheets do not

The Word letters file is on GitHub because it has **no names and no emails**. Anyone can open:

https://github.com/JPGitHub1207/typingmind/raw/cursor/four-corners-event-machine-6a19/four-corners-research/Four_Corners_29_Sept_Letters.docx

The keep-lists are different. They contain names, emails, addresses and phone numbers. This GitHub repo is **public**. Putting those spreadsheets next to the Word file would publish the mailing list.

Cursor Cloud also cannot copy files onto your Mac, and Cursor Web currently has **no download button for files it cannot preview**. `.xlsx` and `.zip` do not preview, so those artifact links 404 after a blank page. That is a Cursor product limit, not a missing file.

## What to open instead (this agent’s Files panel)

These are the same lists, in formats Cursor can preview:

1. **`OPEN_ME_Four_Corners_named_lists.html`** — tables plus a **Download this list as CSV** button. Excel opens CSV.
2. **`Four_Corners_EC_P1_letter_wave.md`** — the 97-person EC P1 letter wave as a table.
3. **`Four_Corners_SW1_SE1_P1_letter_wave.md`** — the 30-person SW1/SE1 P1 letter wave as a table.

P1 is the 29 September L&D letter. P2 is the same kind of buyer. P3 is a different room.

If the HTML still 404s, open this agent in **Cursor Desktop** (not the browser) and use the Files panel there.

## Ways that would make Excel download like Word

None of these can be done from this cloud agent alone:

- Connect **Google Drive** in Cursor MCP so the named `.xlsx` files can be uploaded to your Drive.
- Make a **private** GitHub repo (not this public `typingmind` repo) and put the Excel there.
- Run a **local** Cursor agent in the folder that already holds the original BounceBan / Pearl extracts; it can write Excel next to those files on your Mac.
