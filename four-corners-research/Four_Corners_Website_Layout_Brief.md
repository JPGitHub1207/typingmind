# Website layout — keep the templates, stop filling every slot

The live page (fetched 18 August 2026) is not mainly a copy problem. It is a **layout** problem: the Wix event/club template has more sections than you have unique information, and every section is stuffed with the same essay.

You asked to keep the current text templates. Do that. **Hide or empty the duplicate slots.** Put a different *job* in each remaining slot. Do not paste the same paragraph four times.

This is a paste-and-hide map, not a rebuild.

---

## What is making the text look bad

1. **The same block repeats four times.** Hero, Upcoming Event, Next Event, and Event Overview all say the title, the two talk titles, the date, the venue, and “Every year organisations invest…”. Scrolling feels like the page is stuck.
2. **Everything is a heading.** Event title, subtitle, speaker names, “Event Overview”, leftover “Let’s Do This” — all shout. Body copy then looks like a wall under banners.
3. **Talk slots got the long version.** The Content Overview fields are holding 150–200 word abstracts. Those fields are built for 40–60 words. Long prose in a stacked card looks like a Terms page.
4. **Speaker bios are CVs.** The Guest Contributor template is a name + one line. Petra-length paragraphs make the strip twice as tall as the talks.
5. **FAQ is printed twice.** Accordion labels, then the same answers as body text, then the accordion again. That is leftover template behaviour: you filled the FAQ widget *and* a text strip.
6. **Facts disagree,** which also makes the layout feel messy: 14:00 vs 14:30, 2.5 hours vs 14:00–17:30, £400 with no VAT.

Fix the layout by **using fewer fields**, not by writing more.

---

## The rule

| Keep | Hide / leave empty |
|---|---|
| One hero | Second “Upcoming Event” *or* “Next Event” — not both |
| One facts strip (Event Overview) | Any extra banner that repeats the same title |
| “Your place includes” (four short lines) | The leftover heading **Let’s Do This** |
| Two talk cards, short | Long abstracts in those cards |
| Two speaker cards, one line each | Full CVs (put them on a Speakers page later if you want) |
| Venue | “Clubhouse of all community events” |
| FAQ **accordion only** | FAQ answers duplicated as a text strip underneath |
| Form once, at the bottom | A second “Respond to your invitation” mid-page |

If a strip would say something the strip above already said, hide it.

---

## Intended scroll (eight strips)

Use this as the page order. If the template has more strips, hide them.

```
1. Hero          — title, two talk titles, who it's for, button
2. Facts         — date / time / place / price  (four columns)
3. Includes      — four short lines, not paragraphs
4. The question  — ONE paragraph, ~80 words, nowhere else
5. Two talks     — two cards: title + 40–60 words + speaker name
6. Speakers      — photo, name, one credential line, talk title
7. Venue         — address, map, food
8. FAQ + form    — accordion, then the booking strip
```

That is the whole page. Nothing else.

---

## Typography inside Wix (no new template)

These are settings, not new copy.

- **One H1 on the whole page.** That is the afternoon title. Speaker names are H3. “Event Overview” / “Next Event” / “Content Overview” can stay as the template’s section label, or be deleted if Wix lets you hide the label.
- **Body column: narrow.** Full-width Wix text is why it feels messy. On each text strip: padding left/right ~18–22% (or “narrow” / max-width ~640px). Do this even if you change nothing else.
- **More air between strips, less inside cards.** Increase strip padding (80–120px). Reduce gap between a heading and its one paragraph. The page should look like rooms, not a spreadsheet.
- **Do not put the overview in quote style.** One pull-quote is fine (“Are we solving the wrong problem?”). The rest is body text.
- **Subtitle is one line under the title**, same strip, smaller type — not a second giant heading stacked on the first.
- **Alternate strip colour:** white / warm off-white. Do not set long text over a photo.
- **Buttons:** one word-job. `Request a place`. Not `Respond to your invitation`. Same label in hero and footer. No third button in the middle.
